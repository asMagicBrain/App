# Search and outline

[Documentation](README.md)

## Find what you need

| If you know… | Use… |
| --- | --- |
| A filename or path | **Go to file**, or `Cmd+P` on Mac / `Ctrl+P` on Ubuntu. |
| Words in a saved file | **Search**. |
| Words in the file you are editing | Editor Find, which includes unsaved text. |
| A repository name | The filter in the repository list. |

Outside text fields, `t` opens Go to file and `/` opens content search. These shortcuts do not interrupt typing in an editor or input.

Content search searches saved local files, not private drafts or GitHub. It skips ignored, private, binary, and unsupported files. If results reach a limit, narrow your search; the visible list may not include every match.

## Jump to a heading

Open **Outline** from the window bar, then select a heading. The document scrolls to that heading in Preview, Code, or Edit. The outline follows your reading position.

Outline starts closed. Resize it or close it again to make room for the document. Plain text and documents without Markdown headings have no heading list.

## Return to a reading position

Use the **Back** and **Forward** arrows beside the document path to return to a file, view and scroll position. Local drafts stay intact. History lasts for the current app session and keeps up to 100 locations.

## Follow a portable reference

If a collection supplies document IDs, **Copy reference** copies a reference to the saved bytes. Choose **Open reference…** to paste one. If two installed repositories share an ID, choose which copy to use. Missing or changed content is reported instead of silently substituting another version.

**Evidence context** shows optional author declarations such as the observation date, build and scope. These declarations are not independent verification; a measured result remains distinct from a planned target. Ordinary files do not need metadata.
