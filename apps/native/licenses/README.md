# Supplemental dependency notices

The installed react-arborist 3.16.0 and react-remove-scroll-bar 2.3.8 packages declare MIT but omit license text. This directory supplies their upstream notices; `provenance.json` records source URLs, applicable versions, and saved-byte SHA-256 hashes.

- [react-arborist](https://raw.githubusercontent.com/jameskerr/react-arborist/d74c4ec696ba98c1a4e981075f6d60cdff3e290b/LICENSE): notice from the exact npm release gitHead.
- [react-remove-scroll-bar](https://raw.githubusercontent.com/theKashey/react-remove-scroll-bar/master/LICENSE): maintainer notice; the npm gitHead lookup was unavailable.

Packaging accepts a fallback only when package name, version, and stored hash match. It retains installed dependency notices too. Package code and versions are unchanged.
