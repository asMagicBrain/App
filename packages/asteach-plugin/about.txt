asTeach prepares courses with distinct Instructors and editable Student candidate roots, complete class packages, teaching calendars and separately released Student repositories. Review complete candidate files, source paths and hashes before local promotion or GitBook-ready ZIP export. Existing course identities, legacy pages and optional team workflows are preserved. Repository code is read and packaged as data; it is never executed automatically. Requires asMagicBrain 0.2.22 or a compatible development host. GitHub actions remain separately connected and reviewed.
