# GitHub theme colors

Colors are adapted from the official [primer/github-vscode-theme](https://github.com/primer/github-vscode-theme) 6.3.5 Marketplace package. Its MIT license is included. No extension code is executed or bundled.

Workbench colors map to shared CSS variables; TextMate colors map to existing CodeMirror semantic classes. This is a color adaptation, not a complete VS Code theme engine.
