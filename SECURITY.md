# Report a security issue

Email [AncoraSIR@gmail.com](mailto:AncoraSIR@gmail.com) with **asMagicBrain security** in the subject, or use GitHub's private vulnerability reporting if enabled. Keep sensitive details out of public issues.

Send a short description first. Ordinary email is not end-to-end encrypted; arrange a secure transfer method before sharing sensitive evidence. Prefer a synthetic example and never send credentials.

Include:

- App version/build or source tag, operating system, and architecture.
- Steps to reproduce, expected and actual behavior, and likely impact.
- The smallest example that demonstrates the issue, with personal details removed.

Security fixes target the current 0.2 preview line. Earlier packages may not receive fixes. See [platform limits](docs/platform-and-limits.md).

Test only data and accounts you are authorized to use, with originals preserved and isolated copies. The [architecture guide](contributing/architecture.md#trust-boundaries) describes the security boundaries; [data and recovery](docs/data-and-recovery.md) explains how to preserve affected work.
